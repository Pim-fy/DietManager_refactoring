# DietManager

먹은 음식과 먹을 계획을 기록하고, 하루 섭취량을 개인별 권장 섭취량과 비교하는 식단 관리 서비스입니다.
Thymeleaf로 만든 기존 프로젝트를 React와 Spring Boot로 다시 구성한 리팩토링 프로젝트입니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| 대시보드 | 하루 섭취(식품 영양정보 표시 형식), 오늘 식단 계획, 몸무게 변화, 이번 주 칼로리 추이를 한 화면에서 확인합니다. 신체 기록이나 활동량이 없으면 권장량 계산에 필요한 입력을 안내합니다. |
| 섭취 기록 | 식약처 식품 검색, 내 식품(즐겨찾기·최근 식품), 직접 입력으로 끼니별 기록을 남기고 수정·삭제·복구합니다. 권장량을 넘으면 경고합니다. |
| 식단 계획 | 미리 세운 계획을 먹은 뒤 섭취 기록으로 옮깁니다. 같은 계획은 한 번만 옮길 수 있습니다. |
| 신체 기록 | 키와 몸무게를 기록하고 수정·삭제·복구합니다. |
| 기록 추이 | 주간·월간 칼로리와 체중 그래프, 날짜별 표를 보여줍니다. 칼로리 그래프에는 날짜별 권장 칼로리 기준선을 함께 그립니다. |
| 내 정보 | 계정, 프로필(성별·생년월일·목표), 활동량, 비밀번호를 관리합니다. |

권장 섭취량은 프로필, 신체 기록, 활동량으로 Mifflin–St Jeor 기준에 따라 개인별로 계산하며, 지난 날짜는 그날 적용 중이던 목표와 활동량을 기준으로 합니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React 19, Vite 8 |
| 백엔드 | Java 21, Spring Boot 4, Spring Security(JWT), Spring Data JPA |
| 데이터베이스 | MySQL, Flyway |
| 외부 API | 식약처 식품영양성분 API |
| 테스트 | JUnit(H2·MySQL 통합 테스트), Vitest, Playwright |

## 프로젝트 구조

화면과 서버를 분리한 구조입니다. 브라우저의 화면이 REST API로 서버에 요청하고, 서버는 데이터베이스와 외부 식품 API를 다룹니다.

```
브라우저 화면 (React)  ──REST API──▶  API 서버 (Spring Boot)  ──▶  데이터베이스 (MySQL)
                                                │
                                                └──▶  식약처 식품영양성분 API
```

**API 서버**는 공통 영역과 기능별 모듈로 나뉩니다.
- 공통 영역은 인증(JWT 발급·검증), 오류 응답 형식, 설정처럼 모든 기능이 함께 쓰는 부분을 맡습니다.
- 기능별 모듈은 사용자·인증, 프로필, 신체 기록, 식품, 섭취 기록, 권장량, 식단 계획, 통계로 나뉩니다.
- 각 모듈 안은 요청을 받는 계층, 업무 규칙을 처리하는 계층, 데이터를 저장·조회하는 계층으로 나뉩니다.
- 데이터베이스 구조는 버전별 변경 이력으로 관리합니다.

**화면**은 기능별 화면 묶음과 공통 요소로 나뉩니다.
- 기능별 화면 묶음(대시보드, 섭취 기록, 식단 계획, 신체 기록, 기록 추이, 내 정보)은 각자 화면, 상태 처리, 서버 요청을 함께 가집니다.
- 공통 요소는 서버 요청과 로그인 유지, 여러 화면이 함께 쓰는 화면 부품과 스타일을 맡습니다.

API 목록은 [API.md](API.md)를 참고하세요.
